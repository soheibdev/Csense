# 🛡️ CSense – Cybersecurity Awareness Platform

CSense is a modern **cybersecurity awareness training platform** designed to educate employees through interactive learning, quizzes, gamification, and real-time behavioral tracking.

The system simulates real-world cyber threats such as phishing, weak passwords, and social engineering attacks while providing a structured learning journey.

---

## 🚀 Features

### 👨‍🎓 User Side
- Interactive onboarding (Welcome → Login)
- Learning modules:
  - What is CSense
  - Social Engineering
  - Password Security
  - Phishing Awareness
  - Physical Security
- Video-based learning system
- Quiz system after each module
- Final exam (15 questions)
- Gamification system:
  - XP points
  - Badges
  - Progress tracking
- Unlock system (PC access simulation after 80%+ score)

---

### 🧑‍💼 Admin Dashboard
- Employee monitoring dashboard
- Quiz performance tracking
- Risk analysis system
- Behavioral insights
- User creation (admin-managed accounts)
- Module progress analytics

---

## 🧠 System Concept

CSense is built around a **gamified cybersecurity training flow**:

1. Welcome Page  
2. Login  
3. Learning Modules  
4. Quiz → Result  
5. Progressive learning path  
6. Final Exam  
7. Access Unlock (based on performance)
